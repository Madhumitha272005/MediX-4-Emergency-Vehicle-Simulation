# MEDIX-4: Smart Electric Emergency 4-Wheeler 🚑

**Faster Response. Smarter Care. Saving Lives.**

## 📌 Project Overview

MediX-4 is a smart electric emergency four-wheeler designed to provide faster medical assistance in crowded cities, narrow roads, college campuses, and rural areas. The project focuses on developing a compact, eco-friendly electric ambulance concept integrated with intelligent technologies for emergency response and patient care.

The system combines a 51.2V Lithium Iron Phosphate (LFP) battery, a Permanent Magnet Synchronous Motor (PMSM), GPS-based vehicle tracking, intelligent hospital routing, IoT-based patient vital monitoring, and automatic hospital pre-alert functionality.

A web-based 3D simulation demonstrates the vehicle design, powertrain components, driving environments, battery operation, charging mechanisms, and emergency response workflow.

## ✨ Key Features

- **3D Vehicle Visualization:** Interactive visualization of the MediX-4 electric ambulance and its components.
- **Smart Dashboard:** Displays vehicle speed, battery status, motor power, patient information, and emergency alerts.
- **Hospital Navigation:** Uses Dijkstra's shortest-path algorithm to identify suitable hospitals.
- **Traffic Simulation:** Uses the Intelligent Driver Model (IDM) to simulate vehicle movement in different traffic conditions.
- **GPS Tracking:** Supports live vehicle location tracking.
- **IoT Patient Monitoring:** Demonstrates monitoring of ECG, heart rate, SpO₂, blood pressure, and other vital parameters.
- **Battery Management:** Visualizes LFP battery operation, charging, and energy management.
- **Solar Energy Support:** Demonstrates solar-assisted auxiliary power.
- **3D Component Visualization:** Provides detailed views of the battery pack, PMSM motor, motor controller, and vehicle interior.
- **Emergency Response Workflow:** Demonstrates patient pickup, hospital communication, and emergency pre-alert.

## 🛠️ Technologies Used

- **Frontend:** React 18, HTML5, CSS3, JavaScript
- **3D Visualization:** Three.js, WebGL
- **3D Modelling:** Blender
- **Build Tool:** Vite
- **Runtime:** Node.js
- **Algorithms:** Dijkstra's Algorithm, Intelligent Driver Model (IDM)
- **Battery Simulation:** Constant Current / Constant Voltage (CC/CV) charging model
